👩‍💼 HR Dashboard – Power BI

📌 Project Overview

An interactive HR Analytics Dashboard built with Microsoft Power BI to analyze employee data, attendance, salaries, and employee attrition.

The dashboard is designed to help HR teams monitor workforce metrics and gain insights for better decision-making.

🎯 Project Objectives

- Monitor total employees and workforce distribution.
- Analyze employee attendance and absence.
- Analyze current salaries and payroll.
- Identify employee attrition and turnover trends.
- Provide interactive HR reports and KPIs.
- Enable detailed employee-level analysis.

🛠️ Tools & Technologies

- Power BI Desktop
- Power Query
- DAX
- Excel
- Data Modeling & Relationships

📊 Dashboard Pages

1. Executive Summary

Provides a high-level overview of the most important HR KPIs.

2. HR Overview

Shows employee distribution, salary metrics, attendance, and other workforce insights.

3. Attendance Analysis

Analyzes attendance, absence, leave, and trends over time.

4. Salary Analysis

Analyzes current salaries, average salary, payroll, and salary distribution.

5. Attrition Analysis

Analyzes employees who left the organization and compares attrition across departments and other dimensions.

6. Employee Details

Provides detailed employee-level information using Drill Through.

📈 Key KPIs

- Total Employees
- Average Current Salary
- Total Current Payroll
- Attendance Rate
- Absence Rate
- Total Employees Left
- Attrition Rate

⚙️ Power BI Features Used

- Data Modeling
- Relationships
- DAX Measures
- Power Query
- Calendar Table
- Cards & KPIs
- Slicers & Filters
- Conditional Formatting
- Drill Through
- Tooltips
- Bookmarks
- Buttons & Page Navigation

📂 Dataset

The project uses an Excel-based HR dataset containing information about:

- Employees
- Departments
- Attendance
- Salary History
- Calendar

💡 Key Insights

The dashboard allows HR teams to quickly identify:

- Workforce distribution by department and city.
- Attendance and absence patterns.
- Salary distribution and payroll information.
- Departments with higher employee attrition.
- Employees requiring further attention based on attendance.
